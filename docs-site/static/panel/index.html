Round 1 — Know Your Server
  • SSH in from your desktop
    Double-click "Connect to Server.bat" in your DropBox folder
  • Run health check
    Type health in terminal — see what's green and what's not
  • See running containers
    Type dps — shows every Docker container and its status
  • Open Homepage dashboard
    Open :3000 in your browser — visual overview of all services
Round 2 — Understand Docker
  • Read container logs
    Type docker logs npm — see what NPM is doing. Ctrl+C to stop.
  • Restart a container
    Type docker restart uptime-kuma — watch it come back on its own
  • Look inside a project folder
    Type cd /srv/docker/npm && ls — see what makes up a project
  • Explore Portainer
    Open :9443 — click Containers, click a container, look at logs and details
Round 3 — Secure & Protect
  • Change NPM default password
    Open :81, login admin@example.com / changeme, change it immediately
  • Add monitors in Uptime Kuma
    Open :3001, add HTTP monitors for npm, portainer, homepage
  • Run your first backup
    Type server-backup in terminal
  • Check security status
    Type sec — see firewall, fail2ban, SSH config
Round 4 — Go Public
  • Get a domain name
    Buy one on Cloudflare (~$10/year). Point nameservers to Cloudflare.
  • Set up Cloudflare tunnel
    Create tunnel in Cloudflare Zero Trust, add public hostnames
  • Access a service from your phone
    Put one service on a domain, open it from outside your network
  • Set up Discord alerts
    Create a Discord webhook, paste it into Uptime Kuma notifications
